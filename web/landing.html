Run your own

  1. Get it

    git clone https://gitlab.com/niharokz/natlas.git && cd natlas
cp .env.example .env && mkdir -p config && cp natlas.example.yml config/natlas.yml

  2. Set the login in .env

    openssl rand -hex 32     # NATLAS_SECRET_KEY (and NATLAS_DEVICE_KEY)

    Plus NATLAS_USERNAME, NATLAS_PASSWORD, NATLAS_DATA_DIR (your files) and TZ.

  3. Start it behind HTTPS

    docker compose run --rm natlas check && docker compose up -d --build

    Point your proxy at natlas:8080, sign in, then Add to Home Screen or install the APK.

Just looking? sh scripts/dev.sh runs it on localhost:8080 with sample data. Everything else is in the README.
